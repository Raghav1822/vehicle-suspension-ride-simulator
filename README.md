# vehicle-suspension-ride-simulator
 
[![Live demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-68d8e6)](https://raghav1822.github.io/vehicle-suspension-ride-simulator/)

An interactive quarter-car suspension digital twin that simulates a vehicle crossing a road profile with bumps, ripples, and a pothole. It reports ride RMS acceleration, peak body acceleration, suspension travel, and an ISO-inspired comfort grade.

## Run locally

```bash
npm test
npm run serve
```

Open `http://localhost:8080`.
Interactive quarter-car suspension ride comfort and road profile simulator
